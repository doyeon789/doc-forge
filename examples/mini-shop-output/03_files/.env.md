## In one line
Local environment file that supplies the runtime settings for the app (values are secret and not shown here) (`.env`).

## Role
This is a `secret` file, so it is documented only from key names (`.env`). It defines three keys: `JWT_SECRET` (signing key for login tokens), `DATABASE_URL` (Postgres connection string) and `PORT` (HTTP listen port). All values are `***`.

## Where it has effect
It is loaded by `dotenv` when `src/config.js` is first required (`src/config.js:1`), and then exposed as config fields.
- `PORT` becomes `config.port`, which defaults to 3000 when unset (`src/config.js:4`). It is used by [`src/server.js`](../03_files/src/server.js.md) to listen (`src/server.js:5`).
- `JWT_SECRET` becomes `config.jwtSecret` (`src/config.js:5`). It is used to sign tokens in [`userService`](../03_files/src/services/userService.js.md) (`src/services/userService.js:13`) and to verify them in [`auth` middleware](../03_files/src/middleware/auth.js.md) (`src/middleware/auth.js:9`).
- `DATABASE_URL` becomes `config.databaseUrl` (`src/config.js:6`). It is used to create the connection pool in [`src/db/index.js`](../03_files/src/db/index.js.md) (`src/db/index.js:4`).
- See [`src/config.js`](../03_files/src/config.js.md) for the single reading point.
