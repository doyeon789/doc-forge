## In one line
In-memory product catalog of about 2,590 generated entries, with a lookup helper by SKU (`src/data/catalog.js:2-2`, `src/data/catalog.js:2595-2598`).

## Why it exists
The route and order code need product data without a database. This file is that source, and it is generated by `tools/gen-catalog` (`src/data/catalog.js:1`).

## Key parts
- `products`: array of `{ sku, name, price }` objects. SKUs run from `SKU-0001` to `SKU-2590`, names are `Item NNNN`, and prices follow a repeating numeric pattern (`src/data/catalog.js:2-2593`).
- `bySku`: a `Map` built once from `products`, so lookups do not scan the array (`src/data/catalog.js:2595`).
- `findProduct(sku)`: returns the product or `null` when the SKU is unknown (`src/data/catalog.js:2596`).
- Exports are `products` and `findProduct` only (`src/data/catalog.js:2598`).

## Watch out when reading
- The file is generated, so edits by hand will be lost on the next run (`src/data/catalog.js:1`).
- Assumption: the prices are placeholder values, because they cycle through a fixed range and the names are all `Item NNNN` (`src/data/catalog.js:2-100`).
- The list route returns only the first 50 entries, so most of the catalog is reachable only by SKU (`src/routes/products.js:7`).
- The file is long. Read the first and last lines, since the middle repeats the same shape.
