# module `data`

## In one line
Holds the product catalog as a generated in-memory list with a SKU lookup helper (`src/data/catalog.js:2-2598`).

## Role
The module is one generated file. It exports the `products` array and `findProduct(sku)`, which returns the product or `null` (`src/data/catalog.js:2595-2598`). The header says it is auto-generated by `tools/gen-catalog` and must not be edited by hand (`src/data/catalog.js:1`). It has no database access and no imports; the SKU index is a `Map` built once at load time (`src/data/catalog.js:2595`). The catalog has about 2,590 entries of the form `{ sku, name, price }` (`src/data/catalog.js:3-2592`).

## Files
- [`src/data/catalog.js`](../03_files/src/data/catalog.js.md): generated product list plus the `findProduct` lookup.

Data files: none.

## Relations to other modules
- Used by [routes](routes.md): `src/routes/products.js` lists the first 50 products and looks one up by SKU (`src/routes/products.js:2`, `src/routes/products.js:6-11`).
- Used by [services](services.md): `src/services/orderService.js` calls `findProduct(item.sku)` when processing an order (`src/services/orderService.js:3`, `src/services/orderService.js:8`).
- Uses no other module (`src/data/catalog.js:1-2598`).
- Hidden connection: the generator `tools/gen-catalog` is not in this repo, so the file can only be regenerated outside it (`src/data/catalog.js:1`).

## Reading order for newcomers
1. [`src/data/catalog.js`](../03_files/src/data/catalog.js.md): read the header and the last lines (`src/data/catalog.js:2593-2598`). The middle is repeated data.

## Watch out when reading
- Do not edit the file by hand; changes are lost when it is regenerated (`src/data/catalog.js:1`).
- The file is large (2,598 lines, ending at its `module.exports`), so open it by line range (`src/data/catalog.js:2598`).
- Prices cycle through a repeating pattern (`src/data/catalog.js:3-102`). Assumption: this is sample data, not real prices, because the names are `Item NNNN` (`src/data/catalog.js:3`).
- The catalog is not in the database, which has its own module [db](db.md). Product data and order data live in different places: `orderService` reads products from the catalog and writes orders through `db` (`src/services/orderService.js:1-3`, `src/services/orderService.js:16-19`).
